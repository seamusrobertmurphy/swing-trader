# weekly-review.md — latest Friday review

This file holds **only the most recent** Friday weekly-review. The prior review is overwritten — historical reviews live in git history. The Friday weekly-review routine writes this file.

```
# Week of YYYY-MM-DD

## Performance
- Starting equity: $X
- Ending equity: $X
- Week P&L: $X (Y%)
- SPY return same period: Y%
- Alpha: Y%

## Trades this week
- <date>: <BUY|SELL> <SYMBOL>, <qty> @ <$>, <P&L if closed>
- ...

## What worked
- <one or two bullets>

## What didn't
- <one or two bullets>

## Self-grade
- Letter: <A | B | C | D | F>
- One line: <why this grade>

## Proposed strategy changes
- <diff-style proposal against strategy.md, if any>
- If no changes: "No changes proposed this week."

## Open questions for the user
- <if any>
```

The same content is posted to ClickUp at the end of the weekly-review run.
