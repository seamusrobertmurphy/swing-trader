# learnings.md — carry-forward insights and mistakes to avoid

The user appends to this file during the first weeks of operation. The Friday weekly-review routine reads it and uses it to propose edits to `strategy.md`. The agent may also append its own observations after a routine ends in a way worth remembering.

Each entry uses this block:

```
## YYYY-MM-DD — <one-line title>

- What happened: <facts, ideally with a trade-log reference>
- What the rule should have been: <the principle, stated as if it had been in strategy.md>
- Action: <propose at next weekly review | already in strategy.md | one-off, no rule change>
```

Keep entries terse. Patterns matter more than incidents.
