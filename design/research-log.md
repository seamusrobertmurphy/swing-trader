# research-log.md — dated research notes

Written by the `pre-market` routine and any ad hoc research run. Append-only.

Each entry uses this block:

```
## YYYY-MM-DD pre-market

### Macro
- <one to three lines: overnight prints, futures bias, rates, anything that moves the index.>

### Catalysts today
- <SYMBOL>: <earnings, guide, ratings, secondary, M&A, regulatory>. Direction: <bullish|bearish|mixed>. Source: <Perplexity citation>.

### Watchlist
- <SYMBOL>: <one-line thesis>. Trigger: <what would make this a buy today>. Stop idea: <%>.

### Existing-holdings checks
- <SYMBOL>: <news touching the thesis, if any. If thesis is intact, write "no change".>

### Drafted trades for market-open
- <BUY|SELL> <SYMBOL>: <size %> on <trigger>. Hard stop <%>, trailing <%>.

### Decision summary
- <one line: how many ideas drafted, how much cash will be deployed, anything held back>.
```

A heartbeat entry (`no actionable catalysts today`) is acceptable; silence is not.
